# 702 Notary Plus

Website for 702 Notary Plus, a professional notary service owned by Monashea Wilder.

A static site, with no build step. Open `index.html` in a browser to preview it, or host the folder on any static host (GitHub Pages, Netlify, and so on).

## Structure

- `index.html`, `about.html`, `services.html`, `contact.html`: the pages
- `css/styles.css`: all styles
- `js/main.js`: mobile menu, scroll reveal, contact form
- `assets/img/`: photography (Unsplash)

## Contact form

The request form has no backend. On submit it opens the visitor's email app with a pre-filled message to 702notaryplus@gmail.com. To receive submissions directly, connect the form to a form service such as Formspree or Netlify Forms.
